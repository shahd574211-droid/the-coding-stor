Add Expo assets here or copy from a fresh Expo app:

- icon.png (1024x1024)
- splash-icon.png (splash image)
- adaptive-icon.png (Android, 1024x1024)
- favicon.png (web)

Or run: `npx create-expo-app@latest _tmp --template blank` and copy the `assets` folder from `_tmp/assets` into `mobile/assets`.
